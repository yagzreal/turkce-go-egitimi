# 📢 İHBAR TOOL

Go diliyle yazılmış basit bir terminal uygulamasıdır. Kullanıcılar telefon numarası girerek ihbar yapabilir ve tüm ihbarları görüntüleyebilir.

## Özellikler

- Ana menü sistemi
- Telefon numarası girerek ihbar yapma
- JSON dosyasına veri kaydetme
- Tüm ihbarları listeleme

## Kullanım

1. Go yüklü olmalıdır.
2. Proje klasöründe terminal açın.
3. Aşağıdaki komutu çalıştırın:

   ```bash
   go run main.go
